# Source discipline

Retain source identity, date, jurisdiction, scope, definitions, locator, and relevant version. Prefer primary sources for current technical or professional conclusions. Do not use historical publication metrics as current benchmarks.

Use current-verified only after actually retrieving/supplying the source and assessing effective date and scoped applicability. Use not-retrieved for an applicable but unverified source. Use not-applicable only for sources outside the actual scope, with a reason. Verification of a source is not assurance of compliance.

Load literature and sample reports selectively for methods or deliverable design. A summary's coverage claim is not independently verified coverage. Check rights before redistribution. Do not package restricted books or client information with this generic starter.
