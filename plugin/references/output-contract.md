# Output contract

Close the consolidated client-facing output once with these fields. Scale detail to the task; do not force empty subsections.

- Objective and authorization class: discussion / analysis / draft / review-only / authorized revision, tied to the actual request.
- Claim classes: label material findings in the body or map verified fact / source-derived / assumption / inference / recommendation / evidence gap here.
- Checks performed: actual procedures and scoped results.
- Checks not performed: material omitted, unavailable, or out-of-scope checks.
- Decision-changing limitations: assumptions or gaps that could reverse the conclusion, or none identified within the stated scope.
- Authority status: distinguish this output from approval, issued professional opinion, filing, or execution.
- Disposition: BLOCKED / PASS WITH NON-BLOCKING NOTES / PASS against objective, criteria, and artifact version.

A scoped diagnosis can PASS while an underlying claim remains unconfirmed. Do not mark a requested unsupported valuation, compliance conclusion, or execution PASS merely by changing the objective to a gap memo.

For externally governed material work only, additionally report decision readiness, the referenced/candidate governance outcome if evaluated, and separate execution-authorization status with its evidence. Keep the disposition above as review_disposition; do not infer any of these additional statuses from PASS. See [governance integration](governance-integration.md).
