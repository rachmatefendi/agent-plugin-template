# Analyze Evidence

## Resources and boundary

Read [shared governance](../../references/governance.md) before substantive work. Reuse the same version if already loaded. Apply the relevant [acceptance gates](../../references/acceptance-gates.md), [source discipline](../../references/source-discipline.md), and [output contract](../../references/output-contract.md).

Use the [deliverable template](../../templates/deliverable.md) only when useful. Follow actual user/project authority and available host capabilities.

## Inputs

Requested objective, authorization, artifact/version if supplied, evidence, scope, and acceptance criteria. Ask only for a material missing input; do not invent unavailable data or tool access.

## Workflow

1. Fix the question, scope, period, units, and decision owner where material.
2. Register claims and their source references. Distinguish testimony, verified procedures, assumptions, and inference.
3. Check source context and contradictions using available tools. Preserve unknown values and identify what evidence would resolve them.
4. Perform only supported calculations; document reproducible steps and evaluate material recommendation sensitivities when claiming robustness.
5. Provide conditional findings and options. Apply applicable acceptance gates before disposition.

## Output and acceptance

An evidence-linked analytical memo. A complete gap diagnosis may PASS without proving a claim. A requested definitive conclusion lacking decisive evidence remains BLOCKED. Report actual checks, decision-changing limitations, and authority status using the shared output contract. Stop when scope and required checks are complete.
