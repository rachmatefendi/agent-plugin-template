# Host acceptance checklist

Record host name/version, plugin version, source commit, actual installation/import result, observation date, evaluator, and evidence locations. Run only checks applicable to your declared scope.

- [ ] All three skills are discovered with their intended names and descriptions.
- [ ] A narrow request selects only the relevant capability.
- [ ] Referenced governance and templates can be accessed after installation.
- [ ] Review-only leaves the supplied artifact unchanged.
- [ ] Missing evidence produces the appropriate scoped disposition.
- [ ] Supplied numbers are distinguished from independently verified facts.
- [ ] Tools are invoked only where available and authorized.
- [ ] State and persistence claims match actual host behavior.
- [ ] COPYRIGHT.md is present in the imported package.

For optional integrations, test the actual agent/tool path and state boundaries. Add artifact generation and rendering checks only for formats included in the plugin's scope. Record PASS, FAIL, or NOT_RUN per check; do not infer host acceptance from structural checks.
