# Initial source template release 1.0.0

Copyright © 2026 Rachmat Efendi.

This is the consolidated initial baseline of Agent Plugin Template. It includes three task-based skills, shared governance and output contracts, acceptance gates, optional governance adoption and orchestration profiles, source provenance, developer utilities, and eleven synthetic behavioral fixtures.

AFGS and MDGR references are pinned to inspected commits. APOS research supplies design rationale; it does not establish runtime implementation or empirical validation. Governance adoption defaults to reference-only, and project state defaults to not-persisted.

The package includes no runtime, MCP server, event service, governance kernel, original papers, or professional approval authority. Source validation and utility testing are documented in [the validation report](../VALIDATION.md). All eleven behavioral cases remain not_executed.

This release is a source-template baseline, not installed-host acceptance or externally enforced governance. Its authored contribution remains the repository's specific wording, selection, arrangement, fixtures, and implementation.
