Preserve the current objective and explicit delta. Do not install this template as a live user skill or publish a plugin unless requested. Keep the installable source in plugin/ and developer assets outside it.

Before completing changes, run python scripts/validate.py and python -m unittest discover -s tests -v. Package changes with python scripts/package.py when an archive is requested. Structural checks do not establish behavior PASS.

Use task-based capabilities, shared governance, evidence-by-reference, and minimal orchestration. Do not claim runtime controls, installed discovery, persistence, approvals, professional sign-off, or performed tests without actual evidence. Keep behavior cases not_executed until raw output and a scoped evaluation record exist. Never change accepted artifact content during review-only.
